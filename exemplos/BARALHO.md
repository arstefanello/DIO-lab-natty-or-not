# Baralho das emoções para crianças 🌌

## 📒 Descrição
Consiste em um baralho com 30 cartas diferentes contendo fotos de crianças expressando diferentes emoções. Cada emoção é retratada em 2 cartas totalizando 15 pares de cartas, cada par repreentando uma emoção.  

## 🤖 Tecnologias Utilizadas
- IA Generativa **[Leonardo AI](https://leonardo.ai)** no recurso instant generate para gerar rascunhos das imagens;
- IA Generativa **[Starry AI](https://starryai.com)** para converter a imagem rascunho em fotos;
- Ferramenta Adobe Photoshop para ajustes pontuais nas imagens;
- Ferramenta Corel Draw para organizar as cartas paara impressão.

## 🧐 Processo de Criação
Utilizei o "Instant Generate" do "Leonardo AI" porque esta IA não reserva direitos autorais de imagens geradas pelos modelos específicos de IA generativa quando geradas através de contas free. Por outro lado, o recurso "Instant generate" não disponibiliza para a comunidade e não guarda posteriormente os rascunhos de imagem gerados, além de gerar imagens com poucas distorções se comparado a uma imagem gerada diretamente no "StarryAI". O "StarryAI", por sua vez, através do modelo "Luna Photo" costuma gerar imagens com texturas bastante naturais que se aproximam muito de uma fotografia real e quando a geração é feita a partir de uma imagem de exemplo como as que obtivemos no "Instant Generate" do "Leonardo AI" conseguimos evitar as distorções anatômicas que o modelo Luna AI frequentemente apresenta.

## 🚀 Resultados
Foram construídas as primeiras cartas que apresentam um nível de realismo muito alto, que deverá ser percebido como foto pela maioria das pessoas.
